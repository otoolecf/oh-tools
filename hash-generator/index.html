HMAC (Hash-based Message Authentication Code)

HMAC combines a secret key with your message to create a signature that proves both authenticity and integrity. Use it for:

  • API Authentication: Sign requests with a shared secret key
  • Data Integrity: Verify that data hasn't been tampered with
  • Message Verification: Confirm the sender knows the secret key

How to Generate HMAC:

  1. Select an HMAC algorithm (e.g., HMAC-SHA-256)
  2. Enter your secret key
  3. Enter your message text
  4. Click "Generate Hash" to create the HMAC signature

How to Verify HMAC:

  1. Select the same HMAC algorithm used for generation
  2. Enter the same secret key
  3. Enter the exact same message text (verification compares against this)
  4. Switch to "Verify Hash" mode
  5. Paste the HMAC signature to verify
  6. Click "Verify Hash" - you'll see ✓ VALID or ✗ INVALID

Important: For verification to work, the message, secret key, and algorithm must all match exactly what was used during generation.
